# FraudGuard SA

A machine learning tool that helps South African job seekers check whether a job posting is fraudulent before they respond to it. Paste any posting text, click Analyse, and get one of three verdicts: **Legitimate**, **Suspicious** or **Fraudulent**, with a confidence score, probability breakdown, detected fraud indicators, and safety advice.

Developed for IPJ527C: Advanced Research Project B (Alpha Version), Central University of Technology, Free State.

## How to Run

### Option 1: Standalone interface (no installation)

1. Download `fraudguard_ui.html`
2. Open it in any modern browser (Chrome recommended)
3. Paste a job posting and click **Analyse**

### Option 2: Full Flask application

Requires Python 3.8+ and pip.

```bash
git clone https://github.com/TriggahRay/FraudGuardSA.git
cd FraudGuardSA
pip install -r requirements.txt
python train_model.py   # trains on fake_job_postings.csv + sa_job_postings.csv, creates model.pkl
python app.py           # starts the server
```

Then open `http://127.0.0.1:5000` in your browser.

**Test login details:** none required. The system has no user accounts by design.

## Model and Training Data

The classifier is a Scikit-learn pipeline: TF-IDF vectorisation (unigrams and bigrams, 5,000 features, English stop words removed) feeding a Random Forest (200 estimators, balanced class weights).

Training data combines two sources:

1. **EMSCAD** (Vidros et al., 2017): 17,880 annotated job postings, the standard benchmark in online recruitment fraud research. 4.8% fraudulent.
2. **SA synthetic supplement**: 400 postings (200 fraudulent, 200 legitimate) authored as template families from documented South African scam patterns (registration fees, WhatsApp-only contact, fake parastatal hiring, mining and overseas placement scams) and realistic local recruitment language (SANC, SACE, ECSA registration, CTC salary ranges, PNet/Careers24 application routes). Generated by `generate_sa_dataset.py`. All companies, phone numbers and details are fictitious. No real personal information is used (POPIA, Act 4 of 2013).

## Performance (80/20 stratified split, 3,576 EMSCAD test postings)

| Metric | Value |
|--------|-------|
| Accuracy | 98.0% |
| ROC-AUC | 0.992 |
| Fraudulent precision | 1.000 |
| Fraudulent recall (at 0.5 cutoff) | 0.590 |

Evaluated at the system's actual three-tier thresholds:

| | Flagged Fraudulent | Flagged Suspicious | Called Legitimate |
|---|---|---|---|
| Fraudulent postings (173) | 53.2% | 14.5% | 32.4% missed |
| Legitimate postings (3,403) | 0.0% | 0.2% | 99.8% correct |

The system warns the user (Suspicious or worse) on roughly 68% of real fraud and never wrongly branded a legitimate posting as Fraudulent in testing.

A held-out family test (two SA scam types and two SA legitimate sectors excluded entirely from training) showed the model flags unseen SA scam types with 100% accuracy, because South African scams share transferable markers regardless of the cover story: upfront fees, WhatsApp contact, and requests for ID and banking details.

## Known Limitations and Defects

1. **Miss rate on subtle fraud.** About a third of fraudulent postings in the EMSCAD test set score below the Suspicious threshold. These are scams written in normal recruitment language without common keyword patterns. This is an inherent limitation of lexical (TF-IDF) features and motivates the LSTM comparison planned for the next stage.
2. **Over-flagging of unfamiliar legitimate sectors.** In the held-out family test, 50% of legitimate SA postings from sectors absent from training (nursing, administration) were flagged Suspicious. None were wrongly called Fraudulent. Mitigation: broaden legitimate SA training coverage across more sectors.
3. **Synthetic SA data.** The SA supplement is template-generated, not collected from live platforms. Web scraping was excluded for platform Terms of Service and ethics reasons. Manually collected postings remain a next-stage task.
4. **English only.** The model has not been tested on postings in other South African official languages.
5. **Text only.** The classifier ignores metadata such as company registration, poster history, or contact domain, which prior research shows are strong fraud signals.
